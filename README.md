# Messianic Praise! 2026 — Media Rota app

Installable web app (PWA) for the media team rota.

- `/` — the live app, reading names from the Google Sheet (refreshes every 30s)
- `/trial/` — trial version with sample names
- `config.js` — sheet ID, event day, Apps Script URL for leader editing
- Test any time of the night with `?now=2026-11-27T23:15`

Hosted with GitHub Pages.
