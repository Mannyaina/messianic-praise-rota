# Messianic Praise! 2026 — Media Rota app

Installable web app (PWA) for the media team. Live link: https://mannyaina.github.io/messianic-praise-rota/

- Reads the rota live from the Google Sheet (every 10 seconds, on open, and on pull-down)
- Shift sign-in shared between phones; leader alerts via ntfy
- `config.js` — sheet ID, event day, ntfy topics, leader PIN (hashed)
- `/trial/` — same live app (kept so early home-screen installs keep working)

Hosted with GitHub Pages.
